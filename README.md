# Romantic Apology Web Application ❤️

A single-page, aesthetically beautiful, romantic apology website designed with soft pastel tones, glassmorphism cards, gentle animations, floating heart effects, background music player, Polaroid memory gallery, animated promises, and a live customization editor.

## ✨ Features

- **Soft Pastel Aesthetics**: Light pink, lavender, baby blue, and misty rose colors with glassmorphism blurs.
- **Background Animations**: Upward drifting heart bubbles and soft glowing bokeh particles canvas.
- **Typewriter Apology Letter Card**: Apology letter typed character by character with replay and skip controls.
- **Polaroid Memories Gallery**: Realistic polaroid cards with 3D hover tilt, tape accents, and lightbox full-size viewer.
- **Animated Promise Checklist**: Promises appearing on scroll with interactive heart checkmarks.
- **"Take Your Time" Confetti Interaction**: Custom heart confetti burst and warm hug pop-up modal.
- **🎵 Ambient Music Synthesizer**: Web Audio API soft ambient lullaby chord synthesizer with mute toggle and sound visualizer.
- **✏️ Live Customization Modal**: Drawer to live-edit letter text, photo captions, and promises directly on the page.

## 🚀 Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Bundle**:
   ```bash
   npm run build
   ```
